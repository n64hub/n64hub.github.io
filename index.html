N64 Hub

N64 games in the browser, recompiled to run natively with WebAssembly and WebGPU.

Built on N64Recomp, mostly from other people's recomps, and not endorsed by their authors. Bring your own ROM.

Firefox plays these games slower on built-in graphics like yours. If a game stutters, play it in Chrome.

Firefox on a phone can't play these games. Its WebGPU doesn't run them, so they won't start here. Open this page in Chrome to play.
